# Public/Private Boundary

This repo is intended for public-safe methods, templates, examples, and skills.

## Public Repo May Contain

- reusable methods
- schemas
- public-safe templates
- dummy examples
- generic skills
- install and usage docs

## Private Repo Should Contain

- real private data
- secrets or credentials
- raw notes
- customer or employer-internal details
- unpublished strategy
- applications, negotiations, or other sensitive records

## Rule

Use fictional examples in this repo. Keep real data in a private repo, then publish only reviewed and sanitized outputs.
